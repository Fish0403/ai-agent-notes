# LangGraph 总览

LangGraph 是 LangChain 团队的 Agent 编排框架。核心思想：把 Agent 的决策流程建模成**有向图**——节点负责"做什么"，边负责"做完之后去哪"。

## langchain-core 三原语

LangGraph 依赖 langchain-core 的三个基础概念：

1. **消息** — `HumanMessage`、`SystemMessage`、`AIMessage`、`ToolMessage`，通过 `tool_call_id` 关联工具调用和结果
2. **工具** — `@tool` 装饰器从函数签名自动生成 schema，`bind_tools()` 绑到模型上
3. **模型** — `init_chat_model` 根据名字选 provider，或直接用 OpenAI SDK

## LangGraph 四个核心概念

1. **State** — 流经所有节点的共享数据，用 `Annotated[list, operator.add]` 定义追加规则
2. **Node** — 执行单元，签名为 `State → dict`，只返回需要更新的字段
3. **Edge** — 节点之间的跳转，分普通边（固定路线）和条件边（运行时决定）
4. **StateGraph** — 建图 → 注册节点 → 连边 → `compile()` 编译

## 两个进阶能力

- **Checkpoint** — 每次节点执行后自动保存 State 快照，中断后可从断点恢复。用 `thread_id` 区分会话
- **Human-in-the-Loop** — `interrupt_before` 在指定节点前暂停，等人工批准后用 `app.invoke(None, config)` 继续
